# gatonet
GatoNet - Uma sátira às plataformas de streaming e aos sites de filmes piratas, desenvolvida com HTML, CSS e JavaScript para um projeto acadêmico de Front-End.

**GatoNet** é um projeto desenvolvido para um trabalho acadêmico de Front-End no curso de Análise e Desenvolvimento de Sistemas (ADS). 

A proposta é criar um site fictício de streaming que satiriza as plataformas tradicionais de filmes e séries, além dos famosos sites de procedência duvidosa. Com uma identidade visual própria, textos humorísticos e funcionalidades interativas, o projeto explora conceitos fundamentais de desenvolvimento web utilizando **HTML, CSS e JavaScript**.

O objetivo é unir criatividade e programação, transformando uma atividade acadêmica em uma experiência divertida e irônica sobre o universo do streaming e da pirataria digital.
